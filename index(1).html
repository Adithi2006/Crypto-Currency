Adithi — QuickDApp Documentation

Overview

Adithi is a contract-backed DApp generated with QuickDapp. It is bound to an ERC20 token contract deployed on the Remix VM (in-browser blockchain). The DApp provides a frontend interface for interacting with the contract's token functionality.

How to Use

  1. Open the DApp in QuickDapp Preview — Use the QuickDapp Preview panel within Remix IDE to load the Adithi DApp.
  2. View token info — Read-only functions (name, symbol, decimals, totalSupply) display token metadata. Use balanceOf with an address to check token balances.
  3. Transfer tokens — Use the transfer function to send tokens from your account to another address.
  4. Approve spending — Use approve to authorize a spender address to transfer tokens on your behalf.
  5. Transfer on behalf — Use transferFrom to move tokens between addresses if you have sufficient allowance.
  6. Check allowance — Use allowance to verify how much a spender is authorized to spend.

Note: Because the contract runs on Remix VM, all interactions occur within the Remix IDE environment. The DApp cannot be accessed by external wallets or published as a public DApp in its current state.

Limitations

  • Remix VM only: The contract is deployed on Remix VM (vm-osaka), an in-browser blockchain. It is not reachable outside Remix IDE, and the DApp cannot be published as a working public DApp in its current state.
  • No external gateway: The DApp has not been deployed to IPFS and has no gateway URL, so there is no external website available.
  • Contract coverage not verified: No frontend call references were found for any ABI functions. This does not mean the features are unsupported, only that the static source scan did not detect supported call patterns.
  • Contract source not configured: The contract source path is not configured, so implementation details such as access control, modifiers, and internal validation cannot be documented from source.
  • No description configured: The DApp description metadata is not configured.

Safe Updates

  • Frontend updates: Use the QuickDapp "Ask AI to Update" feature to modify the frontend source files. Do not edit dapp.config.json manually.
  • Contract binding restrictions: Contract address, ABI, or network binding changes are outside normal frontend updates. To add or replace a contract binding, use the QuickDapp update modal and confirm the change in the UI.
  • Contract source: The contract source path is not configured. Without source access, implementation behavior cannot be inferred from the ABI alone.
